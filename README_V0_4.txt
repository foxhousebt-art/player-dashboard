PLAYER DASHBOARD V0.4 — BASE VISUELLE VERROUILLÉE

Cette version marque le passage des maquettes au produit réel.

Direction artistique :
- noir dominant
- traits fins olive/vert
- interface plus futuriste et plus minimaliste
- personnage petit, style arcade/pixel dans l'encadré PLAYER
- aucune frise d'évolution visible
- aucun panneau d'équipement inutile

Fonctionnel :
- L = +1 niveau
- R = reset niveau 1
- niveau sauvegardé dans le navigateur
- animation LEVEL UP
- personnage légèrement animé
- moteur d'évolution du personnage préparé
- l'évolution ne peut apparaître QUE dans l'encadré PLAYER

Paliers personnage :
1 / 5 / 10 / 17 / 20 / 35 / 50 / 62 / 75 / 84 / 95 / 100

IMPORTANT :
Les fichiers de sprites sont structurés et prêts.
La prochaine étape sera de produire les 12 sprites propres dans le même style arcade,
sans modifier une seule ligne de la mise en page.

Ensuite :
1. brancher les données réelles
2. connecter Google Sheets / formulaire téléphone
3. déclencher XP et LEVEL UP automatiquement
